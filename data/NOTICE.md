# Observation credits and reuse

Source images: Courtesy NASA/JPL-Caltech. Archived by the NASA Planetary Data System Imaging Node; produced by JPL's Multimission Image Processing Subsystem for the Mars Exploration Rover mission. The original PDS3 labels remain embedded in each `.img` file.

These are Spirit Navcam EDR products from sol 767, dataset `MER2-M-NAVCAM-2-EDR-OPS-V1.0`. `provenance.json` records the exact product URLs and SHA-256 digests. Calibration is read directly from each product's CAHVOR label in its stated rover reference frame.

The repository's MIT license covers original project software and documentation, not a relicensing of NASA/JPL source imagery. Images and image-derived textures/video retain their source credit. Follow the [JPL image use policy](https://www.jpl.nasa.gov/jpl-image-use-policy/), including source credit and no implied NASA, JPL or Caltech endorsement. No NASA/JPL logos are included. Dependencies and system fonts retain their respective licenses.

Archive overview and documentation: [PDS Imaging Node / MER](https://pds-imaging.jpl.nasa.gov/portal/mer_mission.html).
